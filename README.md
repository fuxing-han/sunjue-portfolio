# SunJue's WORLD

孙珏的完整个人作品集网站，包含品牌 IP、AI 模特与电商、TVC 广告、GUCCI 美妆和产品电商五个项目。

## 部署

这是无需安装依赖或构建的静态网站。入口为 `index.html`，所有 `asset-*` 文件均需保留在相同目录。

GitHub Pages：在仓库 Settings → Pages 中选择 Deploy from a branch，分支选择 `main`，目录选择 `/ (root)`。

## 内容展示

项目一、项目二包含三个分类及依次跳转的底部导航。展示版本不包含编辑入口或编辑面板。联系方式可直接查看并一键复制。
